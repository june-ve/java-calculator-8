# 문자열 덧셈 계산기
입력한 문자열에서 숫자를 추출하여 더하는 '문자열 덧셈 계산기'를 구현해 보자.
***
## 기능 목록
- [ ] 기본 구분자 - 쉼표(`,`) 또는 콜론(`:`)을 사용하여 문자열의 숫자 합계 계산
- [ ] `//`와 `\n` 사이에 위치하는 문자를 커스텀 구분자로 지정하여 문자열의 숫자 합계 계산
    - 예시: `//;\n1;2;3` => `6`
- [ ] 빈 문자열 입력 시 0 반환
- [ ] 숫자 하나 입력 시 해당 숫자 반환
- [ ] 숫자 외 문자 입력 시 `IllegalArgumentException` 발생 처리
